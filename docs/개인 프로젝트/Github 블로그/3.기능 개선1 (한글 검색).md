# 한글 검색


---


just-the-docs를 실행한 후 기능을 살펴보니 검색기능에서 개선점이 보였다.


영문 검색은 잘 되는데 한글 검색이 안된다ㅠ


![영문검색 시](https://devshjeon-blog-images.s3.ap-northeast-2.amazonaws.com/_images/%EA%B0%9C%EC%9D%B8%20%ED%94%84%EB%A1%9C%EC%A0%9D%ED%8A%B8/Github%20%EB%B8%94%EB%A1%9C%EA%B7%B8/%EA%B8%B0%EB%8A%A5%20%EA%B0%9C%EC%84%A01%20%28%ED%95%9C%EA%B8%80%20%EA%B2%80%EC%83%89%29/1.png)


![한글검색 시](https://devshjeon-blog-images.s3.ap-northeast-2.amazonaws.com/_images/%EA%B0%9C%EC%9D%B8%20%ED%94%84%EB%A1%9C%EC%A0%9D%ED%8A%B8/Github%20%EB%B8%94%EB%A1%9C%EA%B7%B8/%EA%B8%B0%EB%8A%A5%20%EA%B0%9C%EC%84%A01%20%28%ED%95%9C%EA%B8%80%20%EA%B2%80%EC%83%89%29/2.png)


한글 검색이 안되는 원인을 찾아보니 just-the-docs는 전문검색으로 _`lunrjs`_ 라이브러리를 사용하고 있는데, 지원하는 언어 중 한글이 존재하지 않았다.


![%E1%84%89%E1%85%B3%E1%84%8F%E1%85%B3%E1%84%85%E1%85%B5%E1%86%AB%E1%84%89%E1%85%A3%E1%86%BA_2023-06-28_18.47.27.png](https://devshjeon-blog-images.s3.ap-northeast-2.amazonaws.com/_images/%EA%B0%9C%EC%9D%B8%20%ED%94%84%EB%A1%9C%EC%A0%9D%ED%8A%B8/Github%20%EB%B8%94%EB%A1%9C%EA%B7%B8/%EA%B8%B0%EB%8A%A5%20%EA%B0%9C%EC%84%A01%20%28%ED%95%9C%EA%B8%80%20%EA%B2%80%EC%83%89%29/3.png)


Theme를 바꿔야 하나 고민하면서 Github 이슈창을 기웃거리는 도중 나와 같은 이슈를 갖고있고 해결책을 찾았다는 댓글을 발견했다.


![%E1%84%89%E1%85%B3%E1%84%8F%E1%85%B3%E1%84%85%E1%85%B5%E1%86%AB%E1%84%89%E1%85%A3%E1%86%BA_2023-06-28_18.55.17.png](https://devshjeon-blog-images.s3.ap-northeast-2.amazonaws.com/_images/%EA%B0%9C%EC%9D%B8%20%ED%94%84%EB%A1%9C%EC%A0%9D%ED%8A%B8/Github%20%EB%B8%94%EB%A1%9C%EA%B7%B8/%EA%B8%B0%EB%8A%A5%20%EA%B0%9C%EC%84%A01%20%28%ED%95%9C%EA%B8%80%20%EA%B2%80%EC%83%89%29/4.png)


해당 repository를 들어가서 설정을 확인해보니 Lunr 에서 공식 지원하지 않는 언어에 대해 Addon이 있었다!


[https://github.com/MihaiValentin/lunr-languages](https://github.com/MihaiValentin/lunr-languages)


적용방법은 다음과 같다.

1. lunr.ko.min.js, lunr.multi.min.js, lunr.stemmer.support.min,js를 다운받아 lunr.min.js 위치로 이동

	![%E1%84%89%E1%85%B3%E1%84%8F%E1%85%B3%E1%84%85%E1%85%B5%E1%86%AB%E1%84%89%E1%85%A3%E1%86%BA_2023-06-28_19.08.53.png](https://devshjeon-blog-images.s3.ap-northeast-2.amazonaws.com/_images/%EA%B0%9C%EC%9D%B8%20%ED%94%84%EB%A1%9C%EC%A0%9D%ED%8A%B8/Github%20%EB%B8%94%EB%A1%9C%EA%B7%B8/%EA%B8%B0%EB%8A%A5%20%EA%B0%9C%EC%84%A01%20%28%ED%95%9C%EA%B8%80%20%EA%B2%80%EC%83%89%29/5.png)

2. 프로젝트에서 lunr.min.js를 검색해서 import하는 부분을 찾아 추가한 파일에 대해서 import

	![%E1%84%89%E1%85%B3%E1%84%8F%E1%85%B3%E1%84%85%E1%85%B5%E1%86%AB%E1%84%89%E1%85%A3%E1%86%BA_2023-06-28_19.13.33.png](https://devshjeon-blog-images.s3.ap-northeast-2.amazonaws.com/_images/%EA%B0%9C%EC%9D%B8%20%ED%94%84%EB%A1%9C%EC%A0%9D%ED%8A%B8/Github%20%EB%B8%94%EB%A1%9C%EA%B7%B8/%EA%B8%B0%EB%8A%A5%20%EA%B0%9C%EC%84%A01%20%28%ED%95%9C%EA%B8%80%20%EA%B2%80%EC%83%89%29/6.png)

3. `.prettierignore` 도 추가해 주었다.

	![%E1%84%89%E1%85%B3%E1%84%8F%E1%85%B3%E1%84%85%E1%85%B5%E1%86%AB%E1%84%89%E1%85%A3%E1%86%BA_2023-06-28_19.10.31.png](https://devshjeon-blog-images.s3.ap-northeast-2.amazonaws.com/_images/%EA%B0%9C%EC%9D%B8%20%ED%94%84%EB%A1%9C%EC%A0%9D%ED%8A%B8/Github%20%EB%B8%94%EB%A1%9C%EA%B7%B8/%EA%B8%B0%EB%8A%A5%20%EA%B0%9C%EC%84%A01%20%28%ED%95%9C%EA%B8%80%20%EA%B2%80%EC%83%89%29/7.png)

4. 검색 처리하는 부분에 `this.use(lunr.multiLanguage('en', 'ko'));` 코드 추가

적용 후 한글 검색이 잘 되는 것을 확인할 수 있다.


![%E1%84%89%E1%85%B3%E1%84%8F%E1%85%B3%E1%84%85%E1%85%B5%E1%86%AB%E1%84%89%E1%85%A3%E1%86%BA_2023-06-28_19.15.44.png](https://devshjeon-blog-images.s3.ap-northeast-2.amazonaws.com/_images/%EA%B0%9C%EC%9D%B8%20%ED%94%84%EB%A1%9C%EC%A0%9D%ED%8A%B8/Github%20%EB%B8%94%EB%A1%9C%EA%B7%B8/%EA%B8%B0%EB%8A%A5%20%EA%B0%9C%EC%84%A01%20%28%ED%95%9C%EA%B8%80%20%EA%B2%80%EC%83%89%29/8.png)


다음 글에서는 Notion API를 사용해서 데이터베이스 정보를 가져와 포스트를 자동으로 만들어주는 기능에 대해서 다루겠다.
