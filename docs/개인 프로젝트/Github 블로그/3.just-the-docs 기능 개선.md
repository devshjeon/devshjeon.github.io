해당 repository를 들어가서 설정을 확인해보니 Lunr 에서 공식 지원하지 않는 언어에 대해 Addon이 있었다!


[https://github.com/MihaiValentin/lunr-languages](https://github.com/MihaiValentin/lunr-languages)


적용방법은 다음과 같다.

1. lunr.ko.min.js, lunr.multi.min.js, lunr.stemmer.support.min,js를 다운받아 lunr.min.js 위치로 이동

	![%E1%84%89%E1%85%B3%E1%84%8F%E1%85%B3%E1%84%85%E1%85%B5%E1%86%AB%E1%84%89%E1%85%A3%E1%86%BA_2023-06-28_19.08.53.png](https://s3.us-west-2.amazonaws.com/secure.notion-static.com/f32e4d14-1421-421b-90b1-3775d8d25bbc/%E1%84%89%E1%85%B3%E1%84%8F%E1%85%B3%E1%84%85%E1%85%B5%E1%86%AB%E1%84%89%E1%85%A3%E1%86%BA_2023-06-28_19.08.53.png?X-Amz-Algorithm=AWS4-HMAC-SHA256&X-Amz-Content-Sha256=UNSIGNED-PAYLOAD&X-Amz-Credential=AKIAT73L2G45EIPT3X45%2F20230628%2Fus-west-2%2Fs3%2Faws4_request&X-Amz-Date=20230628T121528Z&X-Amz-Expires=3600&X-Amz-Signature=a830cac0bebb8710d2ff174f8d614bd9811eaa6eb918c6e55d29743a0eb77245&X-Amz-SignedHeaders=host&x-id=GetObject)

2. 프로젝트에서 lunr.min.js를 검색해서 import하는 부분을 찾아 추가한 파일에 대해서 import

	![%E1%84%89%E1%85%B3%E1%84%8F%E1%85%B3%E1%84%85%E1%85%B5%E1%86%AB%E1%84%89%E1%85%A3%E1%86%BA_2023-06-28_19.13.33.png](https://s3.us-west-2.amazonaws.com/secure.notion-static.com/6e6df3b4-79cb-4029-81a0-dd30e94e56fd/%E1%84%89%E1%85%B3%E1%84%8F%E1%85%B3%E1%84%85%E1%85%B5%E1%86%AB%E1%84%89%E1%85%A3%E1%86%BA_2023-06-28_19.13.33.png?X-Amz-Algorithm=AWS4-HMAC-SHA256&X-Amz-Content-Sha256=UNSIGNED-PAYLOAD&X-Amz-Credential=AKIAT73L2G45EIPT3X45%2F20230628%2Fus-west-2%2Fs3%2Faws4_request&X-Amz-Date=20230628T121528Z&X-Amz-Expires=3600&X-Amz-Signature=672e271e836f8f7d442c6ae9237c3ba06a4381132409939e3e136bdda777d839&X-Amz-SignedHeaders=host&x-id=GetObject)

3. `.prettierignore` 도 추가해 주었다.

	![%E1%84%89%E1%85%B3%E1%84%8F%E1%85%B3%E1%84%85%E1%85%B5%E1%86%AB%E1%84%89%E1%85%A3%E1%86%BA_2023-06-28_19.10.31.png](https://s3.us-west-2.amazonaws.com/secure.notion-static.com/9d6c256b-0379-4192-a9cf-c1f7cc97b185/%E1%84%89%E1%85%B3%E1%84%8F%E1%85%B3%E1%84%85%E1%85%B5%E1%86%AB%E1%84%89%E1%85%A3%E1%86%BA_2023-06-28_19.10.31.png?X-Amz-Algorithm=AWS4-HMAC-SHA256&X-Amz-Content-Sha256=UNSIGNED-PAYLOAD&X-Amz-Credential=AKIAT73L2G45EIPT3X45%2F20230628%2Fus-west-2%2Fs3%2Faws4_request&X-Amz-Date=20230628T121528Z&X-Amz-Expires=3600&X-Amz-Signature=1beca253da82fde47abec378ea0c6b7f6817082b593eff70a08b27f550515a0a&X-Amz-SignedHeaders=host&x-id=GetObject)

적용 후 한글 검색이 잘 되는 것을 확인할 수 있다.
