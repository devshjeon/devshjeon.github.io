# Notion 연동


---


Notion 작성한 포스트를 배포하기 위해 아래와 같은 프로세스로 작업하였다.

1. 포스트 구조와 동일하게 데이터베이스 생성
2. Notion 데이터베이스를 가져와 마크다운 파일로 다운로드하는 스크립트 작성

# 데이터베이스 구조


---


just-the-docs 포스트의 구성을 확인하고 Notion 데이터베이스와 매핑하는 작업을 진행하였다.


### 계층 구조


Layout 메뉴를 보면 2중 구조로 되어있는데 해당 페이지를 소개하는 파일과 하위 파일로 구성되어 있는 것을 확인하였다.


또한, 하위 페이지가 있으면 페이지 설정 정보에 `has_children: true` 이 추가되고 하위 페이지는 `parent: {parent의 title명}`, 2단계 하위 페이지는 `grand_parent: Layout` 가 추가되는 것을 확인할 수 있다.


그리고 동일 메뉴 내 순번을 지정하기 위해 `nav_order` 항목을 추가한 것을 확인할 수 있다.

위의 정보를 토대로 아래 컬럼을 갖는 Notion 데이터베이스를 구성하였다.

- 최상위폴더
- 상위폴더
- 순번
- 제목
- 메인
	- 메뉴의 대표 페이지, 체크 시 하위 포스트를 갖는 옵션인 `has_children: true` 가 추가됨
- 공개
	- 배포가 되었는지 사용자가 확인하기 위한 용도
- 배포
	- 이번 배포 대상인지 확인하기 위한 용도
- 작성일
	- 현재 사용하지 않지만 추후 기능 개선 여지를 위해 저장

# Github 설정


---


### Access Token 등록


Github 페이지에서 우측 상단 아바타 → Settings → 좌측 메뉴 Developer settings → Personal access tokens에서 아래 권한을 갖는 토큰을 생성한다.

- repo
- workflow
- admin:repo_hook

생성한 토큰은 안전하게 보관한다.


### Action Secret 등록


배포하고자 하는 repository → Settings → 좌측 메뉴 중 Secrets and variables → Actions에서 위에서 생성한 Github Access Token, 데이터베이스 아이디와 Notion 시크릿 키를 등록해준다.

# Notion to Github 코드


---


Notion 데이터베이스에서 포스트를 마크다운 형식으로 가져와 저장하는 스크립트를 작성한다.


`_scripts/notion-import.js`


```javascript
const { Client } = require("@notionhq/client")
const { NotionToMarkdown } = require("notion-to-md")
const moment = require("moment")
const path = require("path")
const fs = require("fs")
// or
// import {NotionToMarkdown} from "notion-to-md";

const notion = new Client({
  auth: process.env.NOTION_TOKEN,
})

// passing notion client to the option
const n2m = new NotionToMarkdown({ notionClient: notion });

(async () => {
  // ensure directory exists
  const root = `docs`

  const databaseId = process.env.DATABASE_ID
  const response = await notion.databases.query({
    database_id: databaseId,
    filter: {
      "and": [
        {
          property: "공개",
          checkbox: {
            equals: true,
          },
        },
        {
          property: "배포",
          checkbox: {
            equals: true,
          },
        },
      ],
    },
  })
  for (const r of response.results) {
    const id = r.id

    // 최상위폴더
    let upUpFolder = ""
    let pUpUpFolder = r.properties?.["최상위폴더"]?.["rich_text"]
    if (pUpUpFolder) {
      upUpFolder = pUpUpFolder[0]?.["plain_text"]
    }

    // 상위폴더
    let upFolder = ""
    let pUpFolder = r.properties?.["상위폴더"]?.["rich_text"]
    if (pUpFolder) {
      upFolder = pUpFolder[0]?.["plain_text"]
    }

    // 순번
    let navOrder = r.properties?.["순번"]?.["number"] || ""

    // 제목
    let title = id
    let pTitle = r.properties?.["제목"]?.["title"]
    if (pTitle?.length > 0) {
      title = pTitle[0]?.["plain_text"]
    }

    // 메인
    let hasChild = r.properties?.["메인"]?.["checkbox"] || false

    // 작성일
    let date = moment(r.created_time).format("YYYY-MM-DD")
    let pDate = r.properties?.["작성일"]?.["date"]?.["start"]
    if (pDate) {
      date = moment(pDate).format("YYYY-MM-DD")
    }

    let header = `---
layout: default
title: ${title}
has_children: ${hasChild}
date: ${date}`

    if (navOrder) {
      header += `
nav_order: ${navOrder}`
    }

    if (hasChild) {
      if (upFolder) {
        header += `
parent: ${upUpFolder}`
      }
    } else {
      header += `
grand_parent: ${upUpFolder}`
      if (upFolder) {
        header += `
parent: ${upFolder}`
      }
    }
    header += `
---`

    const folderPath = upFolder ? `${root}/${upUpFolder}/${upFolder}` : `${root}/${upUpFolder}`
    fs.mkdirSync(folderPath, { recursive: true })

    const mdBlocks = await n2m.pageToMarkdown(id)
    const body = n2m.toMarkdownString(mdBlocks)["parent"]

    //writing to file
    const fTitle = navOrder ? `${navOrder}.${title}.md` : `${title}.md`
    fs.writeFile(path.join(folderPath, fTitle), header + body, (err) => {
      if (err) {
        console.log(err)
      }
    })
  }
})()
```


필요한 npm을 설치한다.


```shell
npm install -D @notionhq/client moment notion-to-md
```


로컬환경에서 환경변수로 `NOTION_TOKEN, DATABASE_ID` 를 세팅하고 실행시키면 `docs` 폴더에 마크다운 파일이 생성된 것을 확인할 수 있다.

- `await notion.databases.query` 코드에서 보면 `공개`와 `배포` 컬럼 모두 체크가 되어있는 포스트만 배포를 진행하도록 하였다. (관리 편의성을 위해)

다음 글에서는 Notion 이미지가 만료되어 배포 후 일정시간이 지나면 보이지 않는 이슈를 해결하기 위해 파일을 로컬에 저장 후 이미지를 AWS S3에 저장하는 내용을 다루겠다.
