# Themes 선정


---


구글에 `jekyll themes` 를 검색하면 수 많은 Themes을 확인할 수 있다. 


나는 아래 선정기준으로 내가 원하는 Themes를 찾기로 했다.


### 선정기준

1. 깔끔한 디자인
	1. 페이지가 복잡하지 않고 간단한가?
2. 커뮤니티 (Github star)
	1. 이슈 발생 시 꾸준하게 지원을 해주는가?
3. 반응형
	1. 모바일에서도 보기 편한가?
4. 검색기능
	1. 전문 검색을 지원하는가?
5. 계층 메뉴구조
	1. 메뉴가 계층으로 구성되어 포스트 관리가 편한가?

[just-the-docs](https://github.com/just-the-docs/just-the-docs)가 5개의 기준을 만족해서 선정하였다.


# Local 환경 구성


---


repository clone을 받기 전 다음을 설치한다.

- rbenv, ruby-build
- bundler, jekyll

### rbenv, ruby-build 설치


rbenv는 ruby 버전관리 패키지로 Homebrew를 이용해서 설치를 진행하였음.


```shell
$ brew update
$ brew install rbenv ruby-build

# rbenv 버전 확인
$ rbenv -v

# 설치 가능한 ruby 버전 조회
$ rbenv install -l

# 원하는 버전의 ruby 설치
$ rbenv install 3.2.2

# 설치 학인 및 현재 사용중인 ruby 버전 확인
$ rbenv versions

# 원하는 버전의 ruby 사용
$ rbenv global 3.2.2

# rbenv 환경변수 등록
$ vi ~/.zshrc 

# 마지막 줄에 추가
[[ -d ~/.rbenv  ]] && \
  export PATH=${HOME}/.rbenv/bin:${PATH} && \
  eval "$(rbenv init -)"

# 적용
$ source ~/.zshrc

# ruby 버전 확인
$ ruby -v
```


### ruby 패키지 설치


```shell
$ gem install bundler
$ gem install jekyll
```


### Repository Clone


[bookmark](https://github.com/just-the-docs/just-the-docs)


프로젝트를 받은 다음 bundler 설치 후 실행한다.


```shell
$ bundler install

$ bundle exec jekyll serve
```
