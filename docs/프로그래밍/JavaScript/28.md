## 데이터 타입


자바스크립트는 동적 타입언어로 변수의 타입 지정 없이 값이 할당되는 과정에서 자동으로 변수의 타입이 결정(타입 추론, Type Inference)됩니다.


자바스크립트 데이터 타입은 크게 **Primitive Type**과 **Reference Type**이 있습니다.


## Primitive Type

- Number
- String
- Boolean
- null
- undefined
- **Symbol (ES6+)**

## Reference Type

- Array
- Function
- RegExp
- **Set / WeakSet**
- **Map / WeakMap**
