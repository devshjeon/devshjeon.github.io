## 키워드

- 객체 리터럴
- Object 생성자 함수
- 생성자 함수

## 요약

- 객체는 키와 값으로 구성된 속성의 집합입니다.
- 객체 생성 방법에는 객체 리터럴, Object 생성자, 생성자 함수 3가지가 있습니다.
- 객체 속성 값 접근에는 마침표 표기법, 대괄호 표기법 2가지가 있습니다.

## 객체 (Object)란?


객체는 키값과 값으로 구성된 속성(property)의 집합으로, 데이터를 의미하는 속성(property)과 데이터를 참조하고 조작할 수 있는 동작을 의미하는 메소드(method)로 구성됩니다.


### 속성 (property)


속성은 키와 값으로 구성됩니다.


속성 키: 빈 문자열을 포함하는 모든 문자열 또는 symbol 값


속성 값: 모든 값


속성 키에 문자열이나 symbol 값 이외의 값을 지정하면 암묵적으로 타입이 변환되어 문자열이 된다. 이미 존재하는 속성 키를 중복 선언하면 선언한 속성이 먼저 선언한 속성을 덮어씁니다.


객체는 속성을 열거할 때 순서를 보장하지 않습니다.


### 메소드 (method)


속성 값이 함수일 경우, 일반 함수와 구분하기 위해 메소드라 부릅니다.


## 객체 생성 방법


자바와 같은 클래스 기반 객체 지향 언어는 클래스를 사전에 정의하고 필요한 시점에 `new` 연산자를 사용해서 인스턴스를 생성하는 방식으로 객체를 생성합니다.


반면, 자바스크립트는 프로토타입 기반 객체 지향 언어로서 클래스라는 개념이 없고 별도의 객체 생성 방법이 존재합니다.


ES6부터 클래스가 도입되었습니다. 하지만 여전히 프로토타입 기반으로 동작하며, 프로토타입 체인과 클로저 등으로 객체 지향 언어의 상속, 캡슐화 등의 개념을 구현한 문법적 설탕입니다.


### 객체 리터럴


중괄호 `{}` 를 사용해서 객체를 생성할 수 있습니다. 중괄호 내부에 속성 정보를 입력하면 해당 속성이 추가된 객체를 생성할 수 있습니다.


{% raw %}
```javascript
const person = {
  name: 'kane',
  gender: 'male'
};

console.log(typeof person) // object
```
{% endraw %}


### Object 생성자 함수


`new` 연산자와 Object 생성자 함수를 호출하여 빈 객체를 생성할 수 있습니다. 빈 객체 생성 이후 속성 또는 메소드를 추가할 수 있습니다.


{% raw %}
```javascript
const person = new Object();
person.name = 'kane';
person.gender = 'male';

console.log(typeof person) // object
```
{% endraw %}


객체 리터럴 방식으로 생성된 객체는 빌트인 함수인 Object 생성자 함수로 객체를 생성하는 것을 단순화시킨 축약 표현입니다.


### 생성자 함수


객체를 마치 템플릿처럼 사용하기 위해 사용하고, 동일한 속성의 인스턴스를 여러 개 생성할 수 있습니다.


{% raw %}
```javascript
function Person(name, gender) {
  let age = 30;     // private
  this.name = name; // public
  this.gender = gender;
}

const person1 = new Person('kane', 'male');
const person2 = new Person('jane', 'female');

console.log(typeof person1) // object
console.log(typeof person2) // object
```
{% endraw %}


`this`는 인스턴스에 바인딩 되어 this와 연결된 속성은 외부에서 참조가 가능하고 생성자 내부에서 선언된 변수는 인스턴스 외부에서 참조가 불가능합니다.


객체 리터럴과 생성자 함수 방식의 차이점은 프로토타입 객체입니다.

- 객체 리터럴의 경우 프로토타입 객체는 Object.prototype입니다.
- 위 코드의 경우 생성자 함수의 프로토타입 객체는 Person.prototype입니다.

## 객체 속성 접근


### 속성 키


객체의 속성 키는 문자열이나 symbol 값을 사용할 수 있고 이외의 값을 지정하면 암묵적으로 문자열로 타입이 변환됩니다.


속성 키는 문자열이므로 따옴표(’ 또는 “)를 사용하고 유효한 이름인 경우 생략이 가능합니다. 반대로 유효한 이름이 아닌 경우 따옴표를 사용해야 합니다.


{% raw %}
```javascript
const person = {
  first-name: 'harry', // SyntaxError: Unexpected token -
  'last-name': 'kane',
  gender: 'male'
  1: 10,
}
```
{% endraw %}


### 속성 값


객체 속성 값에 접근하는 방법은 마침표 표기법(dot notation)과 대괄호 표기법(bracket notation)이 있습니다.


{% raw %}
```javascript
const person = {
  'first-name': 'harry',
  'last-name': 'kane',
  gender: 'male',
  1: 10
}

console.log(person.first-name) // NaN: undefined-undefined
console.log(person[first-name]) // ReferenceError: first is not defined
console.log(person['first-name']) // 'harry'

console.log(person.gender); // 'male'
console.log(person[gender]); // ReferenceError: gender is not defined
console.log(person['gender']); // 'male'

console.log(person['1'); // 10
console.log(person[1]); // 10; person[1] -> person['1'] 변환
console.log(person.1); // SyntaxError
```
{% endraw %}


대괄호 표시법 시 대괄호 내에 들어가는 프로퍼티 이름은 반드시 문자열이어야 합니다.
