## 요약

- `this`는 함수를 호출하는 방식에 따라 바인딩 되는 객체가 달라집니다.
- 일반적으로 함수 호출 시 `this`는 전역 객체를 나타냅니다.
- 화살표 함수의 경우 `this`는 상위 실행 컨텍스트의 `this`를 그대로 사용합니다.
- 메서드 함수의 경우 `this`는 메서드를 호출하는 객체를 나타냅니다.
- 콜백 함수의 경우
- 생성자 함수의 경우

## this 란?


실행 컨텍스트가 생성될 때 (일반적으로 함수 호출 시) 바인딩되는 객체로, 함수를 호출하는 방식에 따라 `this`에 바인딩 되는 객체가 달라집니다.

- 전역공간
- 함수 호출
- 메서드 호출
- 콜백 호출
- 생성자 함수 호출

## 전역공간


전역 공간에서의 `this`는 전역 객체를 나타냅니다.


런타임 환경에 따라 브라우저에서는 `window` 노드에서는 `global` 객체를 나타냅니다.


## 함수 호출 시 


### 선언


선언된 함수 안에서 `this`는  전역 객체를 나타냅니다.


{% raw %}
```javascript
function foo() {
  console.dir(this); // Window
}
foo();
```
{% endraw %}


내부 함수에서도 `this`는 전역 객체를 나타냅니다.


{% raw %}
```javascript
function foo() {
  console.dir(this); // Window
  function bar() {
	  console.dir(this); // Window
  }
  bar();
}
foo();
```
{% endraw %}


### 화살표 함수


arrow 함수의 경우 상위 컨텍스트의 `this`를 그대로 사용합니다.


{% raw %}
```javascript
// example 1
const foo = () => {
	console.dir(this); // Window; 상위 실행 컨텍스트인 전역 실행 컨텍스트의 this 값을 사용
}

foo();

// example 2
const obj1 = {
  foo: function() {
    console.dir(this); // obj1 Object
    const bar = () => {
      console.dir(this); // obj1 Object; 상위 실행 컨텍스트인 foo의 this를 사용
    }
    bar();
  }
}

obj1.foo();
```
{% endraw %}


### 메소드


메소드 형태로 함수를 호출하면 메소드를 호출한 객체가 `this`로 바인딩됩니다.


{% raw %}
```javascript
const obj1 = {
  foo: function() {
    console.dir(this); // obj1 Object
  }
}

obj1.foo();
```
{% endraw %}


메소드 안에 내부함수의 경우 `this`는 전역 객체를 나타냅니다.


{% raw %}
```javascript
const obj1 = {
  foo: function() {
    console.dir(this); // obj1 Object
    function bar() {
      console.dir(this); // Window
    }
    bar();
  }
}

obj1.foo();
```
{% endraw %}


메소드 내부함수 안에 있는 this가 전역 객체가 되지 않도록 우회하는 방법

- `self`, `that` 과 같은 변수에 상위 `this`를 할당해서 사용

{% raw %}
```javascript
const obj1 = {
  foo: function() {
    console.dir(this); // obj1 Object
    const that = this;
    function bar() {
      console.dir(that); // obj1 Object
    }
    bar();
  }
}

obj1.foo();
```
{% endraw %}

- 내부함수를 arrow function 형태로 사용

{% raw %}
```javascript
const obj1 = {
  foo: function() {
    console.dir(this); // obj1 Object
    const bar = () => {
      console.dir(this); // obj1 Object
    }
    bar();
  }
}

obj1.foo();
```
{% endraw %}


### 콜백 함수 호출 시


기본적으로는 함수 내부에서 사용하는것과 동일합니다.


{% raw %}
```javascript
const callback = function() {
  console.dir(this); // Window
}

var obj = {
  foo: function(cb) {
    console.dir(this); // obj Object
    cb();
  }
}

obj.foo(callback);
```
{% endraw %}


이런 경우 콜백 함수에서 obj의 `this`를 명시적으로 지정해줄 수 있는 함수가 있습니다.


**call, apply, bind**


3가지 함수는 모두 특정 함수를 실행시키는데 어떤 `this`를  사용할 것인지를 정할 수 있는 함수입니다.


**call**


`func.call(thisArg[, arg1[, arg2[, …]]])`


thisArg 파라미터에 func에서 사용할 this를 넣어 함수를 실행시킵니다.


**apply**


`func.apply(thisArg, [argsArray])`


thisArg 파라미터에 func에서 사용할 this를 넣어 함수를 실행시킵니다.


func의 파라미터는 배열 형태로 넘겨줍니다.


**bind**


`func.bind(thisArg[, arg1[, arg2[, …]]])`


thisArg 파라미터에 func에서 사용할 this를 넣어 함수를 리턴합니다.


{% raw %}
```javascript
function foo(x, y) {
  console.dir(this, x, y);
}

const obj = {
  name: 'kane'
};

foo.call(obj, 1, 2);
foo.call(obj, [1, 2]);

const bar = foo.bind(obj);
bar(1, 2);

const bar = foo.bind(obj, 1);
bar(2);
```
{% endraw %}


### 생성자 함수 호출 시


생성자 함수 호출의 경우 `this`는 해당 인스턴스 객체를 나타냅니다.


{% raw %}
```javascript
function Foo(a, b) {
  this.a = a;
  this.b = b;
}

const foo = Foo('a', 'b'); // new 연산자가 없으면 전역 객체에 추가
console.log(window.a, window.n);


const foo = new Foo('a', 'b');
console.log(foo.a, foo.b);
```
{% endraw %}
