## 요약

- 문자열은 변경 불가능한 값입니다.
- 자바스크립트는 문자열을 UTF-16 코드 단위 수로 나타내기 때문에 문자 1개가 2바이트 또는 4바이트로 구성될 수 있습니다.
- 특히 이모지의 경우 UTF-16 코드 단위가 2개로 구성되기 때문에 직접 `index`에 접근하면 적절한 유니코드로 변환되지 못하고 `iterator`를 사용하는 함수로 처리해야 합니다.

## String


문자열 String 타입은 텍스트 데이터를 나타내며, UTF-16 코드 단위 수를 나타내는 16비트 부호 없는 정수 값의 나열로 인코딩됩니다. 또한 문자열은 작은 따옴표(’) 또는 큰 따옴표(”) 안에 텍스트를 넣어 생성합니다. 일반적으로 작은 따옴표를 사용합니다.


자바스크립트의 문자열은 원시 타입으로 변경 불가능(immutable)합니다. 이것은 한 번 문자열이 생성되면, 그 문자열을 변경할 수 없다는 뜻입니다.


{% raw %}
```javascript
let name = 'kane';
name = 'jane';
```
{% endraw %}


첫번째 구문이 실행되면 메모리에 ‘kane’ 문자열이 생성되고 식별자 `name`은 메모리에 생성된 문자열 ‘kane’의 메모리 주소를 가리킵니다. 그리고 두번째 구문이 실행되면 이전에 생성된 ‘kane’을 수정하지 않고 새로운 문자열 ‘jane’을 메모리에 생성하고 식별자 `name`은 이것은 가리킵니다. 이때, ‘kane’과 ‘jane’ 모두 메모리에 존재합니다.


문자열은 유사배열로 인덱스를 통해 일부 문자에 접근할 수 있지만, 변경 불가능하기 때문에 수정이 불가능합니다. (수정 시 오류가 발생하지 않고 무시됩니다)


{% raw %}
```javascript
let name = 'kane';
name[0] = 'K';
console.log(name); // 'kane'
```
{% endraw %}


## 이모지 처리 문제점


유니코드 6.0부터 이모지가 유니코드에 추가되었습니다. 이모지는 16비트 코드 유닛 2개로 표현되어 이모지를 표현하는데 2개의 유니코드를 사용하는데 이를 해결하기 위해 `코드 포인트 이스케이프 스퀀스`를 사용할 수 있습니다.


{% raw %}
```javascript
console.log("\uD83D\uDE0A"); // 😊
console.log("\u{1F60A}"); // 😊
```
{% endraw %}


자바스크립트에서는 숫자를 전달받아 유니코드 문자열로 변경해주는 함수가 존재합니다.

- String.fromCodePoint()

	코드 포인트를 숫자로 전달받아 해당하는 유니코드 문자열로 변경해줍니다.


{% raw %}
```javascript
console.log(String.fromCodePoint(0x1f60a)); // 😊
console.log(String.fromCodePoint(128522)); // 😊
```
{% endraw %}

- String.prototype.codePointAt()

	문자열의 n 번째 인덱스에 있는 문자의 코드 포인트를 얻습니다.


{% raw %}
```javascript
"😊".codePointAt(0); // 128522
"😊".codePointAt(0).toString(16); // '1f60a'
```
{% endraw %}


### 이모지 반복


UTF-16 인코딩은 2바이트(16비트) 또는 유닛 1개 또는 2개로 구성합니다. 따라서, 문자 1개가 2바이트 또는 4바이트로 둘 다 구성될 수 있다는 의미입니다.


문자 1개가 4바이트 (유닛 코드 2개)로 구성되는 경우 인덱스로 문자열을 접근 시 문제가 발생합니다.


{% raw %}
```javascript
const emoji = "😊";

for (let i = 0; i < emoji.length; i++) {
  console.log(emoji[i]);
}
// �
// �
```
{% endraw %}


각각의 코드 유닛은 유니코드에 매칭되는 글자가 없기 때문에 깨진 문자로 표현됩니다.


이럴 때 `for-of` 를 사용해서 적절하게 처리할 수 있습니다.


{% raw %}
```javascript
const emoji = "😊";

for (const c of emoji) {
  console.log(c); // 😊
}
```
{% endraw %}


### 이모지 쪼개기


문자열을 나누기 위해 `split` 함수를 사용하면 유닛 코드 단위로 잘려 문자가 깨집니다. 이를 해결하기 위해 `Array.from` 또는 `spread` 표현식을 사용하면 됩니다.


{% raw %}
```javascript
const emoji = "😊";

console.log(emoji.split("")); //  ['\uD83D', '\uDE0A']
console.log(Array.from(emoji)); //  ['😊']
console.log([...emoji]); //  ['😊']
```
{% endraw %}
