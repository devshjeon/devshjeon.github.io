## 약수


약수의 약은 한자로 묶다, 다발을 짓다’ 는 뜻을 갖고 있습니다.


따라서, 어떤 수를 나누어떨어지게 하는 수를 약수라 합니다.


예시) 10의 약수는 1, 2, 5, 10


## 공약수


공약수는 두 수의 약수에 공통으로 들어가는 수입니다.


예를 들어 8과 12의 공약수는 다음과 같습니다.


8의 약수: 1, 2, 4, 8


12의 약수: 1, 2, 3, 4, 6, 12


8과 12의 약수에 공통으로 들어 있는 수는 1, 2, 4 이므로 공약수 입니다.


## 최대공약수


최대공약수는 공약수 중 가장 큰 수 입니다.


최대공약수를 구하는 대표적인 방법은 **유클리드 호제법**이 있습니다.


## 유클리드 호제법


> A, B의 최대공약수는 A를 B로 나눈 나머지가 r일 때 B와 r의 최대공약수와 같다.


위의 내용을 코드로 표현하면 아래와 같습니다.


{% raw %}
```javascript
function gcd(a, b) {
	if (a % b === 0) return b;
	return gcd(b, a % b);
}
```
{% endraw %}


## 최소공배수


최대공약수를 이용하면 최소공배수를 쉽게 구할 수 있습니다.


> A와 B의 최소공배수는 A와 B의 곱을 A와 B의 최대공약수로 나눈 것과 같다.


{% raw %}
```javascript
function gcd(a, b) {
	if (a % b === 0) return b;
	return gcd(b, a % b);
}

function lcm(a, b) {
	return (a * b) / gcd(a, b);
}
```
{% endraw %}


## N개의 최소공배수


확장개념으로 N개 수에 대한 최소공배수는 2개 수에 대한 최소공배수를 순차적으로 구하면 됩니다.


{% raw %}
```javascript
function gcd(a, b) {
	if (a % b === 0) return b;
	return gcd(b, a % b);
}

function nlcm(arr) {
	return arr.reduce((a, b) => a * b / gcd(a, b));
}
```
{% endraw %}
